20.26.5.1_GA
------------
- Implemented support for HX3000 Nodes via a CPU Check - Sends 4x Network details and uses COM1 if HX3K


20.26.3.1_GA
------------
- Made Session state reporting more robust
- Added Hearbeat
- Adds a check for the AMT Serial Port, which will reassign it to COM4 if it is conflicting on COM3
- To aid with the above, the application will not exit if the Serial Port cannot be opened, it will just retry opening the port every 5 Seconds
- Reports full windows version ("Windows 11 Pro 25H2") rather than the 6.1s "Microsoft Windows 11 Pro", this just makes it a little more clear as Windows is always Microsoft, but Windows isnt just Pro


2025.9.1
--------
- Renamed to CoreStation HX Agent
- Add Heartbeat Message every 30 seconds to indicate Service and Node are alive
- Added NEW Linux Build, Architecture to build is determined by build OS


2025.6.1
--------
- Report username for RDP sessions
- Set username to "none" if WTS_SESSION_LOGOFF detected
- Reduced main loop time from 500 to 50 ms to enusure all session state changes are captured
- Added milli-seconds to log timestamp


2025.5.2
--------
- Switch port to COM3 to support MVP congatec COM, Advantec will need COM1 moving to COM3
- Added debug log to C:\ProgramData\ahk\node-win-app if not GA version
- Added auto EV signing to .exe file


2025.4.2
--------
- First release that pushes following on change to COM 1 : 
    - win version
    - ethernet details
    - username
    - hostname
    - session state
    - reset network adapter on network down
